## Useful Homebrew Commands

To install multiple applications at once:

```bash
brew install --cask \
vlc \
telegram \
visual-studio-code \
bitwarden \
obsidian \
rectangle \
iterm2 \
cursor \
keka \
appcleaner \
cyberduck \
transmission \
keepassxc \
mos \
whatsapp \
applite
```

To update all Homebrew-installed applications:

```bash
brew upgrade --cask
```

To remove an application:

```bash
brew uninstall --cask <<application_name>>
```
