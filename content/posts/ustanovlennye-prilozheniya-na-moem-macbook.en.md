## Useful Homebrew commands

Install everything at once:

```bash
brew install --cask \
vlc \
telegram \
visual-studio-code \
bitwarden \
obsidian \
rectangle \
iterm2 \
cursor \
keka \
appcleaner \
cyberduck \
transmission \
keepassxc \
mos \
whatsapp \
applite
```

Update everything installed through Homebrew:

```bash
brew upgrade --cask
```

Remove an application:

```bash
brew uninstall --cask <<application_name>>
```
