### Полезные команды Homebrew

Установить разом всё нужное:

```bash
brew install --cask \
vlc \
telegram \
visual-studio-code \
bitwarden \
obsidian \
rectangle \
iterm2 \
cursor \
keka \
appcleaner \
cyberduck \
transmission \
keepassxc \
mos \
whatsapp \
applite
```

Обновить всё, что поставлено через Homebrew:

```bash
brew upgrade --cask
```

Удалить приложение:

```bash
brew uninstall --cask <<название_приложения>>
```
