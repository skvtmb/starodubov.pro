## Полезные команды Homebrew

Поставить сразу несколько приложений можно одной командой:

```bash
brew install --cask \
vlc \
telegram \
visual-studio-code \
bitwarden \
obsidian \
rectangle \
iterm2 \
cursor \
keka \
appcleaner \
cyberduck \
transmission \
keepassxc \
mos \
whatsapp \
applite
```

Обновить приложения, установленные через Homebrew Cask (приложения с собственным автообновлением brew пропускает, если не добавить `--greedy`):

```bash
brew upgrade --cask
```

Удалить приложение (вместо `название` подставьте имя из команды установки, например `vlc`):

```bash
brew uninstall --cask название
```
