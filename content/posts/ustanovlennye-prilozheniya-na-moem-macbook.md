## Полезные команды Homebrew

Если вы хотите установить несколько приложений сразу, можно использовать команду:

```bash
brew install --cask \
vlc \
telegram \
visual-studio-code \
bitwarden \
obsidian \
rectangle \
iterm2 \
cursor \
keka \
appcleaner \
cyberduck \
transmission \
keepassxc \
mos \
whatsapp \
applite
```

Для обновления всех установленных через Homebrew приложений:

```bash
brew upgrade --cask
```

Для удаления приложения:

```bash
brew uninstall --cask <<название_приложения>>
```
