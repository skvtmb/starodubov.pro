{{- /* Русское склонение «кадр / кадра / кадров» для целого числа */ -}} {{- $n := . -}} {{- $mod10 := mod $n 10 -}} {{- $mod100 := mod $n 100 -}} {{- if and (eq $mod10 1) (ne $mod100 11) -}}кадр {{- else if and (ge $mod10 2) (le $mod10 4) (or (lt $mod100 12) (gt $mod100 14)) -}}кадра {{- else -}}кадров {{- end -}}
