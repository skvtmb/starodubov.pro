# Фото для поста «Екатеринбург в феврале 2026»

Все снимки копируются из папки с исходниками и сохраняются как **00.jpg, 01.jpg, 02.jpg, …** (по порядку).

В посте используются:
- **00.jpg** — обложка и первое фото галереи
- **01.jpg** — Храм на Крови
- **02.jpg** — Плотинка
- **03.jpg** — уличный арт (мурал)
- **04.jpg** — Ельцин Центр
- **05.jpg** — набережная
- **06.jpg – 19.jpg** — остальные снимки галереи

Скопировать все фото одной командой:

```bash
./copy_ekb_photos.sh
# или с указанием своей папки:
./copy_ekb_photos.sh /путь/к/папке/с/фото
```

Если снимков больше 20, добавьте в пост новые строки по образцу галереи (20.jpg, 21.jpg и т.д.).
